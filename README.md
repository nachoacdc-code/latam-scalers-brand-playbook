# LatAm Scalers — Brand Playbook

The definitive brand reference for [LatAm Scalers](https://latamscalers.com). This is a single-file, self-contained brand bible covering the complete visual identity system.

## Live URL

**[View the Brand Playbook →](https://latam-scalers-brand-playbook.vercel.app)**

## What's Inside

| Chapter | Content |
|---------|---------|
| Logo System | Primary lockup, stacked, icon-only, mono, clear space, don'ts |
| Color System | Primary/secondary/semantic palettes, gradients, WCAG contrast |
| Typography | Type scale (H1–Caption), wordmark weight rule, embed code |
| CTA Buttons | 5 styles, light/dark, 3 sizes, CSS specs |
| Iconography | Style rules, recommended libraries, examples |
| Photography | Profile card design, photo treatment, fallback rules |
| Digital Apps | Website header, GSuite email signature, social avatars, favicon |
| Print / Presentations | Business card, 4-slide deck template, brochure header |
| Voice & Tone | Tone attributes, key phrases, phrases to avoid, CTA wording |
| Downloads | SVG/PNG export, favicon package, CSS token copy |
| Version History | Full timeline from research through v6 |

## Tech Stack

- **Zero dependencies** — single `index.html` with inline CSS + JS
- **Google Fonts** — Inter (300–700)
- **SVG rendering** — all logos rendered inline for resolution independence
- **Responsive** — sidebar collapses to hamburger on mobile
- **Print-friendly** — sidebar hides, sections avoid page breaks

## Logo Details

- **Mark**: J1-Diagonal-06 (three ascending bars)
- **Palette**: B — Bright Aqua (`#0A1628` Midnight + `#5EEAD4` Aqua)
- **Typeface**: Inter 400/700 with gradient "l" at 145% scale

## Deploy

This is a static site. Deploy the `brand-playbook/` folder to any host:

```bash
# Vercel
cd brand-playbook
vercel --prod

# Or any static host — just serve index.html
```
